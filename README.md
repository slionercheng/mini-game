# 五子棋在线对战游戏

这是一个基于Web的五子棋在线对战游戏，支持跨平台玩家对战。

## 功能特点

- 基于Web技术，无需安装，任何设备都可以通过浏览器访问
- 实时对战，支持创建和加入房间
- 响应式设计，适配各种屏幕尺寸
- 简洁美观的界面

## 技术栈

- **前端**：HTML5, CSS3, JavaScript, Canvas API
- **后端**：Python, Flask
- **实时通信**：Socket.IO (Flask-SocketIO)

## 安装与运行

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 运行服务器：

```bash
python app.py
```

3. 在浏览器中访问：

```
http://localhost:5000
```

## 游戏规则

1. 两名玩家分别使用红色和蓝色棋子
2. 玩家轮流在棋盘上放置棋子
3. 先将五个或更多棋子连成一条直线（横、竖或斜线）的玩家获胜

## 如何玩

1. 第一个玩家创建房间并获得房间ID
2. 第二个玩家输入房间ID加入游戏
3. 游戏开始后，玩家轮流点击棋盘放置棋子
4. 游戏结束后可以选择重新开始

## 部署

可以将游戏部署到任何支持Python的服务器上，如Heroku、AWS、DigitalOcean等。
